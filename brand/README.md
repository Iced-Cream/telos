# telos brand

**telos** (lowercase), *the elekloader os*. The mark is a lowercase Greek tau (τ, from τέλος, "end, purpose").

| File | Use |
|---|---|
| `telos-logo.png`, `telos-logo-512.png` | stacked lockup: τ, telos, the elekloader os |
| `telos-header.png` | wide lockup for page headers (the README's) |
| `telos-icon-512.png` … `telos-icon-32.png` | the τ alone: avatar, favicon, shop thumbnail |

|---|---|
